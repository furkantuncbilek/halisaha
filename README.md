# SAHA — Halı Saha Kadro & Reyting

PES/FIFA tarzı sahaya oyuncu yerleştir, maç maç reyting gir, form grafiklerini gör.

## Çalıştırma

```bash
npm install
npm run dev
```

## Özellikler

- 5v5 / 6v6 / 7v7 formasyonlar
- Sürükle-bırak diziliş
- Maç maç 0–10 reyting
- Ortalama, form ve sıralama grafikleri
- Paylaşım linki (kadroyu URL ile gönder)

## Build

```bash
npm run build
```
